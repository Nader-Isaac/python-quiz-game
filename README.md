# Python Quiz Game

A simple interactive quiz game built with Python. The project allows users to answer questions and practice basic programming concepts.

## Features

- Display quiz questions.
- Collect answers from the user.
- Check answers.
- Provide feedback based on the user's responses.

## Requirements

- Python 3.x

## How to Run

1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run:

   ```bash
   python "random game.py"
   ```
